# Native-repo packages for Arch and Arch-based distros, installed by
# install.sh via `pacman -S`. One package per line, '#' comments allowed.
#
# This is a starting core set, not a full mirror of Brewfile — package names
# and availability vary (AUR packages are NOT installed by install.sh). Tools
# without a reliable native package (neovim, pyenv, nvm, topgrade, lazygit,
# oh-my-tmux, zsh) are installed separately by install.sh via their own
# upstream installers.
#
# Desktop/GUI apps live in pacman-packages-desktop.txt instead, so a headless
# box doesn't get them.

# Build tools needed by install.sh's from-source builds (pyenv's autotools
# build and zsh's ./configure && make). base-devel is a package *group*;
# `pacman -S --noconfirm base-devel` would actually install it non-interactively
# (--noconfirm answers the member-selection prompt with its default, "all").
# This explicit list is intentionally narrower — it covers what those two
# source builds actually need without pulling in members like autoconf/
# automake/libtool that nothing here uses. (lf's fallback is a prebuilt
# static binary, so it needs no build tools.)
gcc
make
patch
pkgconf

# General tools, otherwise unrelated to builds — grouped here by convention.
fakeroot
cmake
git
curl
wget
tmux
lf

# Needed by install.sh itself for upstream installers below.
# unzip — Nerd Font step; tar — tarball extraction
unzip
tar

# Needed by things this repo actually ships:
# pkgfile     — provides /etc/zsh_command_not_found on Arch, which the
#               oh-my-zsh command-not-found plugin sources; also powers
#               `pkgfile`-style lookup. (The zsh hook needs
#               `source /usr/share/doc/pkgfile/command-not-found.zsh`.)
# fontconfig  — fc-cache, after the font install
pkgfile
fontconfig
